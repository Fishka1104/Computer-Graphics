# Комп'ютерна графіка та мультимедіа

Репозиторій для виконання лабораторних робіт з дисципліни **«Комп'ютерна графіка та мультимедіа»**.

## 📁 Структура проєкту

- **`index.html`** — головна сторінка-хаб з випадаючою навігацією між усіма лабораторними роботами.
- **`style.css`** — загальні стилі інтерфейсу та навігаційного меню.
- **`/lab1`** — Лабораторна робота №1: «Основи створення найпростішої WebGL-програми».
- **`/lab2`** — Лабораторна робота №2: «Робота з пристроями введення та організація взаємодії з користувачем».
- **`/lab2`** — Лабораторна робота №2: «Робота з пристроями введення та організація взаємодії з користувачем».
